# Режим: ВПФ под БСП

## Порядок работы (не отступай)
1. Из ТЗ собери данные: назначение БСП (например `Документ.СчетНаОплатуПокупателю`), название кнопки,
   поля шапки, колонки таблицы, откуда брать данные. Если чего-то не хватает, задай ОДИН вопрос
   одним сообщением.
2. Один вызов `scaffold_vpf`. Логику выборки данных передай сразу в `data_code`
   (тело процедуры `ЗаполнитьДанные(Ссылка, ПараметрыШапки, СтрокиТаблицы, ПараметрыПодвала)`).
3. Один вызов `build_and_check`. Если есть ошибки, правь модуль и повтори.
4. Ответь пользователю: путь к .epf и что проверить руками.

## Запреты
- Не пиши `СведенияОВнешнейОбработке` и регистрацию БСП сам. Это делает `scaffold_vpf`.
- Не вызывай `get_tool_guide` без `section`/`query`.
- После ошибки инструмента НЕ повторяй тот же вызов. Измени аргументы или прочитай нужный раздел справки.
- Не читай модуль целиком, если нужна одна процедура (`get_module_structure`, потом точечное чтение).
- Не создавай лишних форм, команд и реквизитов, которых нет в ТЗ.

## Эталон data_code (структура, подставь свои поля и запрос)
```bsl
	ПараметрыШапки.Вставить("Контрагент", Строка(Ссылка.Контрагент));
	Запрос = Новый Запрос;
	Запрос.Текст = "ВЫБРАТЬ ... ГДЕ Ссылка = &Ссылка";
	Запрос.УстановитьПараметр("Ссылка", Ссылка);
	Выборка = Запрос.Выполнить().Выбрать();
	Итого = 0;
	Пока Выборка.Следующий() Цикл
		Строка = Новый Структура;
		Строка.Вставить("НомерСтроки", Выборка.НомерСтроки);
		СтрокиТаблицы.Добавить(Строка);
		Итого = Итого + Выборка.Сумма;
	КонецЦикла;
	ПараметрыПодвала.Вставить("Итого", Итого);
```

## Формат modify_metadata (если нужна ручная правка)
- Свойства: `properties: [{"name":"Synonym","value":"..."}]`. Пустые элементы запрещены.
- Макет SpreadsheetDocument: вместо `properties` передают объект `template` (cells/merges/areas/columnWidths).
