# Режим: внешние отчёты на СКД

## Порядок работы
1. Из ТЗ выпиши: период, отборы, группировки, показатели, итоги, куда выводить.
2. Создай проект (`create_project`, projectKind=externalObjects, объект ExternalReport.<Имя>).
3. Схему СКД строй через `dcs` (сначала `action='get'`, потом правки). Запрос пиши в наборе данных.
4. КАЖДЫЙ текст запроса проверяй `validate_query` до записи в схему.
5. `build_and_check`.

## Запреты
- Не вызывай `get_tool_guide` без `section`/`query`.
- После ошибки инструмента НЕ повторяй тот же вызов. Измени аргументы.
- Не усложняй: без лишних вариантов настроек, если их нет в ТЗ.
- Для виртуальных таблиц (остатки, обороты) всегда задавай параметры в запросе, а не отбором после.
