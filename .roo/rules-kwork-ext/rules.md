# Режим: расширения конфигурации и багфикс

## Порядок работы
1. Найди место правки: `search_in_code` (мало контекста), `get_module_structure`, `read_method_source`.
   Весь модуль целиком не читай.
2. Заимствуй в расширение МИНИМУМ объектов (`adopt_metadata_object`).
3. Правь через `write_module_source`. Используй аннотации &Перед / &После / &Вместо,
   `&Вместо` только если иначе нельзя.
4. Проверь запросы `validate_query`, затем `get_project_errors`.
5. Выгрузка .cfe (`export_configuration_to_file`) только после `update_database`.
   Перед `update_database` проверь `infobase_sessions` (нет чужих сеансов).

## Запреты
- Не вызывай `get_tool_guide` без `section`/`query`.
- После ошибки инструмента НЕ повторяй тот же вызов. Измени аргументы.
- Не переименовывай и не удаляй объекты типовой конфигурации.
- Не трогай поддерживаемые объекты напрямую. Только через расширение.
