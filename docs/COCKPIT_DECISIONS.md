# Журнал архитектурных решений: Kwork Cockpit & Guard 2.0

## ADR-001: Маршрутизация `order_id` через URL-путь в MCP
- **Контекст:** Roo Code в режиме `streamable-http` не гарантирует передачу кастомных HTTP-заголовков (`X-Order-Id`), что приводило к слиянию контекстов всех заказов в `state/default.json`.
- **Решение:** Добавлены маршруты `/mcp/{profile}/{order_id}` в `edt_guard.py` с наивысшим приоритетом пути над заголовками и аргументами вызовов. Старые эндпоинты `/mcp/{profile}` сохранены для обратной совместимости.
- **Статус:** Принято.

## ADR-002: Дисковое кэширование метаданных с точечной инвалидацией
- **Контекст:** Перезапуск прокси или сброс процесса очищал оперативный кэш, приводя к повторным тяжелым чтениям метаданных конфигурации 1С.
- **Решение:** Реализован двухслойный кэш (RAM + JSON на диске в `state/cache/<project>.json`) с атомарной записью через `.tmp` файлы и селективной инвалидацией по префиксу или имени объекта метаданных.
- **Статус:** Принято.

## ADR-003: Встроенный статический анализатор BSL (Zero-Cost Guard)
- **Контекст:** Ошибки синтаксиса и запросы в цикле приводили к падению сборщика EDT и напрасной трате лимита вызовов заказа (25 calls).
- **Решение:** Проверка BSL-кода на этапе перехвата в прокси (`write_module_source`, `patch_method`) через `guard/bsl_linter.py`. Ошибки возвращаются агенту с `isError=True` без обращения к EDT и без списания бюджета заказа.
- **Статус:** Принято.

## ADR-004: Изоляция сервисного слоя от GUI
- **Контекст:** Необходимость 100% покрытия бизнес-логики unit-тестами без зависимости от графического сервера или оконной подсистемы Windows.
- **Решение:** Модули в `cockpit/services/` реализованы в виде чистых классов/функций без импорта `tkinter` и `customtkinter`. Вся UI-логика инкапсулирована в `cockpit/ui/`.
- **Статус:** Принято.

## ADR-005: Отказоустойчивый парсинг ТЗ Kwork
- **Контекст:** Сетевые сбои или отсутствие API-ключа OpenRouter не должны блокировать работу оператора.
- **Решение:** `IntakeParserService` применяет двухэтапную стратегию: попытка структурирования через OpenRouter LLM с автоматическим безопасным откатом на детерминированный regex-парсер без выброса исключений.
- **Статус:** Принято.
