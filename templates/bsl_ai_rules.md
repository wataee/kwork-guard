# Стандарты и правила генерации кода BSL для ИИ-агентов (1С:Предприятие 8.3)

## 1. Фундаментальные архитектурные запреты (Критические ошибки)
1. **Категорически запрещены запросы в цикле (`BSL002`):**
   - Никогда не вызывай `Запрос.Выполнить()`, `Запрос.ВыполнитьПакет()` или `.Выбрать()` внутри циклов `Для` и `Пока`.
   - Выгружай данные в `Массив` или `ТаблицуЗначений`, передавай в параметры запроса с оператором `В (&МассивЗначений)` и соединяй в одном запросе.

2. **Корректная работа с транзакциями (`BSL006`):**
   - Вызов `НачатьТранзакцию()` обязан быть СТРОГО ДО блока `Попытка`, чтобы при ошибке блокировки не вызывалась отмена несуществующей транзакции.
   - Шаблон:
     ```bsl
     НачатьТранзакцию();
     Попытка
         // Изменение данных
         ЗафиксироватьТранзакцию();
     Исключение
         ОтменитьТранзакцию();
         ЗаписьЖурналаРегистрации(...);
         ВызватьИсключение;
     КонецПопытки;
     ```

3. **Обязательный возврат значений из функций (`BSL007`):**
   - Каждая ветка выполнения в блоке `Функция ... КонецФункции` обязана заканчиваться оператором `Возврат <Значение>`.

4. **Запрет пустых блоков `Исключение` (`BSL005`):**
   - В блоке `Исключение` всегда должен быть вызов `ЗаписьЖурналаРегистрации`, установка описания ошибки или `ВызватьИсключение`.

5. **Запрет изменения `ТекущиеДанные` напрямую (`BSL008`):**
   - Свойство `Элементы.Таблица.ТекущиеДанные` предназначено только для чтения. Присваивать ему значения напрямую запрещено.

6. **Запрет жестко закодированных GUID (`BSL009`):**
   - Не используй литералы UUID вида `"00000000-0000-0000-0000-000000000000"`. Используй поиск по предопределенным элементам или метаданным.

## 2. Стандарты БСП для внешних обработок и печатных форм
1. Внешняя обработка или отчет ОБЯЗАНЫ содержать экспортную функцию `СведенияОВнешнейОбработке()` в модуле объекта:
   ```bsl
   Функция СведенияОВнешнейОбработке() Экспорт
       ПараметрыРегистрации = ДополнительныеОтчетыИОбработки.СведенияОВнешнейОбработке("2.2.2.1");
       ПараметрыРегистрации.Вид = ДополнительныеОтчетыИОбработкиКлиентСервер.ВидОбработкиДополнительнаяОбработка();
       ПараметрыРегистрации.Версия = "1.0.0";
       ПараметрыРегистрации.БезопасныйРежим = Истина;
       
       Команда = ПараметрыРегистрации.Команды.Добавить();
       Команда.Представление = НСтр("ru = 'Выполнить команду'");
       Команда.Идентификатор = "ОсновнаяКоманда";
       Команда.Использование = ДополнительныеОтчетыИОбработкиКлиентСервер.ТипКомандыВызовСерверногоМетода();
       Команда.ПоказыватьОповещение = Истина;
       
       Возврат ПараметрыРегистрации;
   КонецФункции
   ```

## 3. Роли и специализация субагентов
- **BSL Architect:** проектирует структуру реквизитов, табличных частей и связи метаданных в компактном JSON перед генерацией кода.
- **BSL Developer:** пишет лаконичный код по стандартам 1С без неиспользуемых переменных и непустых областей.
- **BSL Reviewer / QA:** валидирует код статическим анализатором, проверяет баланс блоков `#Область / #КонецОбласти` и соответствие транзакций.
