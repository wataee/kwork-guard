# История изменений (CHANGELOG)

## [1.0.0] - 2026-11-07

### Реализовано (WP0 - WP9)

#### WP0: Разведка и базовая линия
- Реализован `tools/discover.py` для безопасного извлечения схем из живого EDT.
- Составлен эталонный `verified_schemas.json` (10 core-инструментов).
- Написан `tests/mock_upstream.py` с поддержкой JSON, SSE и симуляции потери сессий (404).

#### WP1: Бюджет заказа и состояние
- Реализован `guard/state.py` с отслеживанием лимитов заказов (`order_id`).
- Добавлено мягкое предупреждение на 80% бюджета и жесткая блокировка на 100%.
- Реализованы спасительные гейты (`ALLOWED_AFTER_LIMIT`) для сборки и получения ошибок.
- Добавлены loopback-эндпоинты `/admin/orders`, `/admin/orders/{id}/reset`, `/admin/orders/{id}/extend`.

#### WP2: Пакет макросов экстремальной экономии токенов
- Реализован `scaffold_vpf` (ВПФ целиком за 1 шаг).
- Реализован `scaffold_report` (отчет СКД с валидацией запроса за 1 шаг).
- Реализован `scaffold_processor` (обработка с БСП за 1 шаг).
- Реализован `bootstrap_gold` (клонирование проверенных шаблонов на диск за 0 токенов MCP).
- Реализован `get_critical_errors` (фильтрация стилевого шума).
- Реализован `patch_method` (хирургическая замена BSL-методов).
- Реализован `dry_run: true` во всех макросах.

#### WP3: Библиотека эталонов
- Создан каталог `library/` с 8 сниппетами BSL и запросов (НДС 5%, суммы прописью, остатки, маркировка и др.).
- Добавлены MCP-инструменты `library_list` и `library_get`.
- Реализована автоматическая вставка сниппетов в `scaffold_vpf` через `snippet_ids`.
- Реализована утилита `tools/library_verify.py`.

#### WP4: Файл уроков и анализ сбоев
- Реализована запись нормализованных событий ошибок в `state/events.jsonl` с маскированием путей и ID.
- Реализована утилита `tools/weekly_lessons.py` для автогенерации рекомендаций в `rules.md`.

#### WP5: Режим приёма ТЗ (kwork-intake)
- Создан режим `kwork-intake` в `.roomodes` с отключенными инструментами MCP (0 токенов).
- Созданы шаблоны `templates/brief.md` и `templates/brief.schema.json`.
- Создан CLI-валидатор `tools/validate_brief.py`.

#### WP6: Пакет сдачи и макрос `complete_order`
- Реализован макрос `complete_order`: валидация синтаксиса, компиляция, генерация инструкций, текста сообщения для Kwork и локальный Git-коммит.
- Созданы шаблоны `instructions_client.md`, `message_kwork.md`, `checklist_manual.md`.

#### WP7: Кеш чтений и cost_report
- Реализован in-memory `ReadCache` с TTL и инвалидацией по проектам при записи.
- Добавлена ротация логов (5 МБ x 3 файла).
- Реализована консольная утилита `tools/cost_report.py`.

## [1.1.0] - 2026-11-09

### Добавлено: Система управления жизненным циклом заказов и гарантийным контуром
- Реализована утилита `tools/order.py` и батник `order.bat` (команды `new`, `list`, `update`, `deliver`, `warranty`, `sync`).
- Внедрен паспорт заказа `order.json` по схеме `templates/order.schema.json` как единый источник правды.
- Внедрен журнал архитектурных решений `templates/DECISIONS.md` (ADR) для долгосрочной памяти при гарантийных доработках.
- Реализована интеграция с локальным Git: автоматический initial commit при создании заказа, теги `delivered-YYYY-MM-DD` при сдаче, ветки `warranty/YYYY-MM-DD` при гарантийных обращениях.
- Реализована автогенерация Markdown-дашборда `C:\Orders\CLIENTS.md` со сводкой выручки, подсчетом чистой прибыли (выручка минус токены AI) и блоком горящих алертов (дедлайны, зависания, перерасход токенов).
- Тестовое покрытие расширено до 40/40 тестов (`tests/test_order_manager.py`).
