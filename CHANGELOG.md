# История изменений (CHANGELOG)

## [2.0.0] - 2026-11-09

### Добавлено (Kwork Cockpit & Guard 2.0 - Zero-Defect Edition)

#### Kwork Cockpit Desktop Application (GUI)
- Реализовано полноценное десктопное приложение на базе `customtkinter` (тёмная тема, геометрия 1280x840, поддержка Windows).
- Создана точка входа `launch_cockpit.pyw` с подавлением консольного окна и перехватом ошибок в `logs/cockpit_boot.log`.
- Сгенерирована многослойная иконка `assets/cockpit.ico` (16, 32, 48, 256 px).
- Разработан скрипт `tools/install_shortcut.py` и пакетный установщик `install_cockpit.bat` для создания ярлыка `Kwork Cockpit.lnk` на Рабочем столе Windows.
- Реализован механизм single-instance приложения через файл блокировки `state/cockpit.lock` с валидацией PID процесса.

#### Экраны и компоненты Cockpit
- **TopBar:** мониторинг доступности портов EDT MCP (:8765) и Guard (:8766), кнопки запуска/остановки/перезапуска Guard, кнопка «▶ Подготовить рабочее место» (`prepare_workplace`).
- **ViewToday:** умные алерты (горящие дедлайны, исчерпание лимитов вызовов), сводные KPI (пайплайн, часы, маржа), карточки активных заказов («В VS Code», «Промпт в буфер», «Карточка»).
- **ViewOrders:** реестр заказов с полнотекстовым поиском (`Ctrl+K`), фильтрами по статусам и типам.
- **ViewNewOrder:** быстрый интейк ТЗ из Kwork (Regex + AI fallback), создание каталога заказа, `.roo/mcp.json`, Git-репозитория и открытие в VS Code в 1 клик.
- **ViewOrderDetail (6 вкладок):**
  - *Обзор:* управление статусами, учет времени (+0.5ч, +1.0ч), дедлайны, заметки.
  - *Разработка:* переход в VS Code, генерация промпта для Roo, синтаксический BSL-контроль, запуск в тонком клиенте 1С.
  - *ТЗ и Бриф:* редактор `brief.md` и валидация обязательных секций.
  - *Бюджет и Логи:* мониторинг лимита (25 вызовов), кнопки «+10 вызовов» и «Сбросить лимит», история MCP-вызовов.
  - *Сдача в 1 клик:* интерактивный чек-лист, сборка клиентского ZIP с инструкцией и копирование на Рабочий стол (`~/Desktop/1C_Delivery`).
  - *Гарантия и Git:* фиксация архитектурных решений `DECISIONS.md`, перевод на 30-дневную гарантию.
- **ViewFinance:** расчет выручки, маржинальности, затрат на AI и ставки ₽/ч, экспорт отчетов в CSV.
- **ViewTools:** просмотр базы эталонных сниппетов, запуск `library verify`, еженедельных уроков и unit-тестов.
- **ViewSettings:** конфигуратор портов и путей к 1С, маскированный ввод ключа OpenRouter в `.env`, Системный Доктор (10 проверок окружения).

#### Сервисный слой Cockpit (`cockpit/services/`)
- `GuardRunnerService`: управление фоновым процессом Guard, пинг EDT и Guard, подготовка рабочего места и синхронизация MCP-конфигов заказов.
- `OrdersFacade`: управление жизненным циклом заказов, статусами, бюджетами, чек-листами и метриками.
- `IntakeParserService`: детерминированный regex-парсер ТЗ с AI-фоллбэком.
- `PromptBuilderService`: сборка стартовых промптов для Roo Code с контекстом шаблонов и макросов.
- `DeliveryPackagerService`: рендеринг клиентских инструкций и сборка архивов с копированием на Рабочий стол.
- `OneCRunnerService`: автопоиск `1cv8c.exe` с сортировкой по версиям, запуск отчетов/обработок в тонком клиенте, открытие в VS Code.
- `SystemDoctorService`: комплексная диагностика 10 параметров среды разработчика.

#### Модернизация Guard 2.0
- **BSL Linter (`guard/bsl_linter.py`):** статический анализатор баланса блоков BSL (BSL001-BSL005), блокирующий запись поврежденного кода без списания бюджета вызовов.
- **Дисковый ReadCache (`guard/cache.py`):** сохранение кэша на диск в `state/cache/<project>/` с выборочной инвалидацией при модификации модулей.
- **Компактор ответов (`guard/compactor.py`):** очистка технических UUID и пустых полей в JSON-ответах EDT.
- **OpenRouter Billing (`guard/openrouter_billing.py`):** трекинг реального расхода токенов и расчет затрат в USD/RUB.
- **Маршрутизация по URL:** поддержка `/mcp/{profile}/{order_id}` в `edt_guard.py`.

#### Zero-Trust QA & Кодовая культура
- 98 unit-тестов с прохождением 100%.
- Покрытие новых модулей (`guard/*`, `cockpit/services/*`) >= 90% (BsL Linter 100%, Config 97%, State 97%, Billing 97%, OneC Runner 96%, Intake 98%, Zip Packager 92%, Doctor 92%, Cache 93%, Compactor 92%, Facade 90%, Guard Runner 90%, Prompt Builder 91%).
- Строгое соблюдение Zero-Defect правил: 0 комментариев `# ...`, 0 докстрингов внутри методов/классов, 0 заглушек `pass`/`TODO` в целевом коде.
- Проверка AST-линтером `tools/verify_zero_defect.py`.

- Реализован `guard/state.py` с отслеживанием лимитов заказов (`order_id`).

#### WP3: Библиотека эталонов

## [1.1.0] - 2026-11-09

### Добавлено: Система управления жизненным циклом заказов и гарантийным контуром
- Реализована утилита `tools/order.py` и батник `order.bat` (команды `new`, `list`, `update`, `deliver`, `warranty`, `sync`).
- Внедрен паспорт заказа `order.json` по схеме `templates/order.schema.json` как единый источник правды.

- Реализована интеграция с локальным Git: автоматический initial commit при создании заказа, теги `delivered-YYYY-MM-DD` при сдаче, ветки `warranty/YYYY-MM-DD` при гарантийных обращениях.
- Реализована автогенерация Markdown-дашборда `C:\Orders\CLIENTS.md` со сводкой выручки, подсчетом чистой прибыли (выручка минус токены AI) и блоком горящих алертов (дедлайны, зависания, перерасход токенов).
- Тестовое покрытие расширено до 40/40 тестов (`tests/test_order_manager.py`).
