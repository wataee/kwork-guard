# Инструкции для AI-агентов (Roo Code, Claude, Antigravity)

## 1. Архитектура репозитория
- `edt_guard.py` — высокопроизводительный Streamable-HTTP MCP прокси (порт 8766), защищающий EDT MCP (порт 8765).
- `guard/` — сервисы ядра защиты:
  - `state.py`: бюджет вызовов (25 на заказ), спасительные гейты, маршрутизация `order_id`.
  - `cache.py`: двухслойный кэш чтений с дисковой персистентностью и выборочной инвалидацией.
  - `bsl_linter.py`: статический анализатор BSL (проверка парности блоков, запрет запросов в циклах, плейсхолдеры, регистрация ВПФ).
  - `compactor.py`: очистка технических UUID и дублирующих структур ответов EDT.
  - `macros.py`: атомарные макросы генерации артефактов за 1 вызов (`scaffold_vpf`, `scaffold_report`, `scaffold_processor`, `patch_method`, `macro_read_bsl_method`, `complete_order`).
  - `openrouter_billing.py`: контроль расхода средств OpenRouter.
  - `library.py`: библиотека эталонных сниппетов БСП.
- `cockpit/` — десктопное приложение оператора (CustomTkinter):
  - `services/`: чистая бизнес-логика (запуск прокси, фасады заказов, парсер ТЗ, генератор сдачи, запуск 1С).
  - `ui/`: экраны (Сегодня, Заказы, Новый заказ, Карточка, Финансы, Инструменты, Настройки).
- `tools/` — CLI-утилиты (`order.py`, `cost_report.py`, `validate_brief.py`, `weekly_lessons.py`).

## 2. Жесткие правила для разработчиков и агентов
1. Запрещены комментарии (`# ...`) и docstrings внутри функций и классов в `.py` файлах. Читаемость обеспечивается строгой типизацией и декомпозицией.
2. Запрещены `pass`, `TODO`, `NotImplementedError` и глушение исключений. Все ошибки логируются через `RotatingFileHandler`.
3. Пути к проекту вычисляются динамически через `Path(__file__).resolve().parent...` без захардкоженных пользовательских директорий.
4. Перед коммитом все тесты обязаны проходить на 100% (`pytest tests -v`).

- `vpf` (ВПФ) — 12 инструментов. Макрос: `scaffold_vpf`.
- `report` (Отчеты СКД) — 12 инструментов. Макрос: `scaffold_report`.
- `processor` (Обработки) — 14 инструментов. Макрос: `scaffold_processor`.
- `ext` (Расширения) — 18 инструментов.
- `intake` (Приём ТЗ) — 0 инструментов MCP (чистый диалог).
